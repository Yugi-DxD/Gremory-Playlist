# Gremory-Playlist
Playlist de Músicas com informações para OBS sem a necessidade de Plugins Externos.

# Funcionalidades
- Baixo e eficiente consumo de recursos
- Personalizável
- 

Requisitos:
- Open Broadcast Software (https://obsproject.com/pt-br/download)
- Foobar2000 (https://www.foobar2000.org/)
- Now Playing 2 (https://github.com/foxx1337/foo_nowplaying2)
